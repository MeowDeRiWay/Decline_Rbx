# Кінцівки персонажа

Це схема для підготовки моделі. Автоматичне складання кінцівок і програвання
їхніх анімацій ще не підключене: спочатку потрібна авторська модель.
Поточний персонаж без кінцівок продовжує працювати.

У `StarterPlayer/StarterCharacter` залишаємо `Humanoid`, `Head` і поточний
`Body` (під час запуску код перейменовує його на `HumanoidRootPart`).
Не додаємо другу кореневу деталь і не змінюємо розміри чи положення старого
тіла: від нього зараз залежать колізія, камера та положення зброї.

Додати вісім безпосередніх дочірніх Part або MeshPart:

| Деталь | Значення |
| --- | --- |
| LeftUpperArm | Ліва рука від плеча до ліктя |
| LeftLowerArm | Ліве передпліччя, кисть можна включити в цю деталь |
| RightUpperArm | Права рука від плеча до ліктя |
| RightLowerArm | Праве передпліччя з кистю |
| LeftUpperLeg | Ліве стегно |
| LeftLowerLeg | Ліва гомілка зі стопою |
| RightUpperLeg | Праве стегно |
| RightLowerLeg | Права гомілка зі стопою |

Ліво/право — з погляду персонажа. Перед — локальний мінус Z тіла.
Малювати одразу в розмірі й положенні відносно старого тіла, симетрично,
з руками, трохи відведеними від боків. Кожна секція — одна рухома деталь;
декор можна приварювати до її секції, але не через лікоть або коліно.

Для кінцівок: `Anchored=false`, `CanCollide=false`, `CanTouch=false`,
`CanQuery=false`, `Massless=true`. Їхня геометрія поки декоративна і не
розширює зону влучання. Не з'єднувати секції WeldConstraint між собою чи
з тілом: жорсткий шов завадить згину.

## Суглоби для анімацій

Після отримання моделі ставимо Motor6D у місцях з'єднання:

| Motor6D | Part0 | Part1 | Точка обертання |
| --- | --- | --- | --- |
| LeftShoulder | Body / HumanoidRootPart | LeftUpperArm | Ліве плече |
| LeftElbow | LeftUpperArm | LeftLowerArm | Лівий лікоть |
| RightShoulder | Body / HumanoidRootPart | RightUpperArm | Праве плече |
| RightElbow | RightUpperArm | RightLowerArm | Правий лікоть |
| LeftHip | Body / HumanoidRootPart | LeftUpperLeg | Ліве стегно |
| LeftKnee | LeftUpperLeg | LeftLowerLeg | Ліве коліно |
| RightHip | Body / HumanoidRootPart | RightUpperLeg | Праве стегно |
| RightKnee | RightUpperLeg | RightLowerLeg | Праве коліно |

Кожен Motor6D є дочірнім об'єктом Part0. C0 і C1 задають одну й ту саму
світову точку та орієнтацію суглоба: `Part0.CFrame*C0 = Part1.CFrame*C1`.
Плечовий суглоб не повинен обертатися навколо середини плечової деталі.
Це налаштовується під фактичні розміри авторської моделі.

Для редагування анімацій використовуємо копію моделі в Workspace та
Animation Editor. Імена деталей у редакторі та у грі мають збігатися.
Остаточно назвати кореневу деталь `HumanoidRootPart` перед авторством анімацій.
Корінь має залишатися AssemblyRootPart (високий RootPriority на ньому,
кінцівки Massless). Додаємо Animator у Humanoid на сервері.

Перший набір: Idle (цикл), Walk (цикл), Run (цикл), RifleHold (поза рук),
Fire (одноразова віддача), Reload (одноразова). Ходьба керує ногами;
тримання зброї перекриває лише руки. Для цього у верхніх анімаціях не
створюємо ключі ніг. Пізніше додаємо удари та робочі дії.

Анімації публікуємо під власником гри. Після публікації їхні ID треба
підключити до контролера; самого завантаження анімацій у Roblox недостатньо.
Зараз `src/character/Animate.client.luau` навмисно порожній.

Перед увімкненням перевіряємо висоту ніг над землею та HipHeight: нинішнє
значення 0 налаштоване на старе тіло. Зброя зараз тримається на корені,
тому рух рук сам по собі її не рухатиме. Її хват і положення другої руки
будуть підганятися разом із моделлю, зі збереженням Muzzle і прев'ю в HUD.

## Зупинка під час пострілу

Успішний серверний постріл встановлює `ShotMovementUntil` за спільним
серверним годинником. Running блокує ходьбу та спринт до цього часу,
клієнт після стандартного вводу обнуляє напрям руху. Тривалість —
`GameConfig.ShotMovementLockSeconds` (0.2 с). Новий постріл продовжує
дедлайн; відкладених скидань швидкості немає. Перезарядка та відхилені
постріли дедлайн не продовжують. Поворот/прицілювання залишаються доступні.
Корінь не анкериться, зовнішні фізичні поштовхи не блокуються.
