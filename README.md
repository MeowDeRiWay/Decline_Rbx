# Decline — етап 1

Шутер згори з містами. Ця версія — основа для перевірки керування і вступу в місто, а не завершена гра.

## Запуск

1. У VS Code відкрий папку репозиторію, виконай `git pull`, потім `rojo serve`.
2. У Roblox Studio відкрий Decline, підключи плагін Rojo до localhost:34872 та синхронізуй.
3. Натисни Play. Підійди до термінала, натисни E, перемкни професію кнопкою та вибери місто.
4. WASD — рух відносно камери, Shift — біг, миша — напрямок персонажа. Стрибки вимкнені.

## Персонаж гри

Аватар акаунта не використовується. Сервер клонує `ServerStorage/DeclineAssets/PlayerCharacter`. Якщо моделі немає, створює квадратну тестову модель.

Власна модель: Model з Humanoid та HumanoidRootPart, з'єднані частини, усі частини не Anchored. Для R6 потрібні стандартні з'єднання шиї; для нестандартної моделі з іншим скелетом вимкни Humanoid.RequiresNeck. Код розташовує кореневий Part на 4 студси над точкою появи; змінюй цей відступ під розміри моделі. Анімації ще не додані.

## Тестова карта

Під час запуску створюється Workspace/DeclineWorld: Lobby з терміналом і Towns з п'ятьма містами. Біля стін залишено відкритий вхід: функціональні ворота ще не реалізовані. Перший мешканець отримує Leader=true; у Flag записується LeaderUser_ID. Дані міст не зберігаються після закриття сервера. Мер після виходу не замінюється автоматично; перевибори — наступна система.

Flag містить Town_ID, Town_name, Team. Player і персонаж мають User_ID, Town_ID, Leader, Knockout, AFK, Health, Food, Water, Sick. Професія та окремі XP/рівні створені на Player, але нарахування досвіду, бонуси і гілки навичок ще не реалізовані.

Потреби витрачаються лише після вибору міста. Working та LoadKg — серверні атрибути Player для майбутніх робіт та інвентаря. Sick стартує зі 100: спад починається при <=49, шкода при 0, відповідно до задуму. Це шкала стану здоров'я, де більші значення кращі.

Reset починає непритомність на 120 секунд. Після таймера з'являється новий персонаж у місті, старий лишається як труп на 300 секунд. На трупі є CorpseProtectedUntil і HUD показує 60 секунд захисту. Самого інвентаря та обшуку трупів ще немає, тож це лише дані для майбутнього LootService. Повноцінний бойовий DamageService має переводити гравця у Knockout до смерті Humanoid; не завдавай шкоди через пряме встановлення Humanoid.Health=0.

## Ще не реалізовано

Зброя, зомбі, інвентар та лут, ресурсні жили, будівництво/погодження, покращення, професійні бонуси, лікування, вибори мера, дипломатія/торгівля, збереження профілю та 10-хвилинний AFK з пошуком персонажа між серверами. У цьому етапі персонаж видаляється після виходу.

Кожен новий предмет спершу потрібно додавати до ItemConfig.luau, коли буде створено систему предметів.

## Перевірка в Studio

- Start Server з 2 гравцями: вибери однакове місто; лише перший повинен отримати Leader.
- Перевір інше місто, професію, рух WASD, напрямок миші та Shift.
- Reset: 120 секунд непритомності, потім поява у місті та таймер захисту старого трупа.
- Для швидкої перевірки потреб тимчасово зменш стартові food/water в серверному spawn; поверни 100 після тесту.

Rojo build перевіряє структуру проєкту; поведінку фізики та GUI необхідно перевірити у Studio.
